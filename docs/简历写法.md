## 四、高频追问与参考回答

**问：为什么用 JWT 而不用 Session？**
答：JWT 无状态，服务器不用存会话，天然适合前后端分离和水平扩展；缺点是令牌吊销麻烦，所以我配合 1 天过期时间。项目里登录成功后前端把令牌存 localStorage，axios 拦截器自动带上。

**问：密码为什么不能明文存？**
答：数据库一旦泄露，明文密码直接暴露。我用 Argon2 单向哈希，即使拿到数据库也无法反推密码；校验用 `verify_password` 而不是比对哈希字符串。

**问：怎么保证用户只能看到自己的数据？**
答：每个表都带 `user_id`，所有查询强制 `where(user_id == 当前用户)`，接口层通过 `get_current_user` 依赖拿到登录用户，从入口就做了隔离。

**问：金额为什么用 float？**
答：教学项目图简单，float 在极端精度场景有误差；如果上线我会换成 `Decimal(12,2)`，这也是我在 README 里主动说明的已知边界。

**问：SQLite 和 MySQL 怎么切换？**
答：ORM（SQLModel）屏蔽了数据库差异，`DATABASE_URL` 换一行配置即可，代码不用改。
