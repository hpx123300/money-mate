## 四、高频追问与参考回答

**问：为什么用 JWT 而不用 Session？**
答：JWT 无状态，服务器不用存会话，天然适合前后端分离和水平扩展；缺点是令牌吊销麻烦，所以我配合 1 天过期时间。项目里登录成功后前端把令牌存 localStorage，axios 拦截器自动带上。

**问：密码为什么不能明文存？**
答：数据库一旦泄露，明文密码直接暴露。我用 Argon2 单向哈希，即使拿到数据库也无法反推密码；校验用 `verify_password` 而不是比对哈希字符串。

**问：怎么保证用户只能看到自己的数据？**
答：每个表都带 `user_id`，所有查询强制 `where(user_id == 当前用户)`，接口层通过 `get_current_user` 依赖拿到登录用户，从入口就做了隔离。

**问：金额为什么用 float？**
答：教学项目图简单，float 在极端精度场景有误差；如果上线我会换成 `Decimal(12,2)`，这也是我在 README 里主动说明的已知边界。

**问：SQLite 和 MySQL 怎么切换？**
答：ORM（SQLModel）屏蔽了数据库差异，`DATABASE_URL` 换一行配置即可，代码不用改。

## 六、面试拷问清单（15 题，对着练）

> 使用方法：先自己答一遍，答不上的地方回项目代码里找答案，直到能不看代码讲出来。

1. **为什么用 JWT 不用 Session？**
   答：JWT 无状态，服务器不用存会话，天然适合前后端分离和水平扩展；缺点是难主动吊销，所以我设了 1 天过期时间。

2. **密码为什么不能明文存？用了什么算法？**
   答：数据库泄露后明文直接暴露。我用 Argon2 单向哈希，无法反推；校验时用 `verify_password` 而不是比对哈希字符串。

3. **怎么保证用户只能看到自己的数据？**
   答：每张表都带 `user_id`，所有查询强制 `where(user_id == 当前用户)`；`get_current_user` 依赖从 JWT 解析出用户，接口入口就完成隔离。

4. **金额为什么用 float？生产环境怎么办？**
   答：教学项目图简单。float 有二进制精度误差，生产会换成 `Decimal(12,2)`，README 里主动写了这个已知边界。

5. **SQLite 和 MySQL 怎么切换？**
   答：ORM（SQLModel）屏蔽了数据库差异，改 `DATABASE_URL` 一行即可，代码不用动。

6. **数据表之间是什么关系？为什么这么设计？**
   答：User 一对多 Category/Wallet/Transaction/Budget；Transaction 通过外键关联 Category 和 Wallet。用外键保证数据完整性，`user_id` 保证隔离。

7. **流水多了怎么办？**
   答：已实现分页：接口返回 `{total, page, page_size, items}`，用 `LIMIT/OFFSET` 只取一页，前端有分页组件。

8. **统计接口慢怎么办？**
   答：已实现缓存：统计结果先查缓存（Redis，没配时内存兜底），命中直接返回；设 60 秒 TTL，记账/改账时主动清缓存，保证一致性。

9. **缓存怎么保证数据不脏？**
   答：两道保险：短 TTL（60 秒）自动过期 + 写操作（增删改流水）时按用户前缀清空该用户统计缓存。

10. **令牌存在哪里？有什么风险？**
    答：存在 localStorage。风险是 XSS 能读到令牌；改进方案是放 httpOnly Cookie + CSRF 防护，或者短期令牌 + 刷新令牌。

11. **为什么选 Vue3 而不是 React？**
    答：上手快、中文生态资料多、单文件组件对新人友好；两个都常用，React 的组件化思想我也懂，换过去成本不高。

12. **项目怎么部署的？**
    答：Docker 两阶段构建（Node 打包前端 → Python 运行后端），单容器托管前后端；生产可加 MySQL/Redis 容器和反向代理。

13. **为什么写测试？测试覆盖了什么？**
    答：防止改坏旧功能。16 项接口测试覆盖注册/登录/分类/钱包/流水/预算/统计/导出/分页，CI 里每次提交自动跑。

14. **项目哪里还能改进？**
    答：三个方向——① Alembic 做正规数据库迁移（现在是启动时建表）；② 前端补单元测试；③ 金额换 Decimal、接口异步化。诚实说边界，比硬吹强。

15. **这个项目 AI 也能做，怎么证明是你做的？**
    答：三个证据——① 我踩过一堆真实坑（SPA 路由 404、pnpm 11 拦截构建脚本、reactive 忘导入白屏），AI 不会踩坑；② 我能现场改代码；③ 项目里的功能来自我的真实需求（生活费超支想管钱、想知道奶茶花了多少）。
