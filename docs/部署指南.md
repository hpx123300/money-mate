# 🚢 部署指南

目标：项目跑在公网 URL 上，手机能访问，简历链接能点。

## 第 0 步：安装 Docker（Mac）

1. 下载 [Docker Desktop for Mac](https://www.docker.com/products/docker-desktop/)；
2. 安装并打开，等右上角鲸鱼图标变绿；
3. 终端验证：`docker --version`。

## 第 1 步：本地 Docker 构建验证

```bash
cd money-mate
docker build -t moneymate .
docker run -p 8000:8000 moneymate
```

打开 http://127.0.0.1:8000，功能正常后再部署到云平台。

## 第 2 步：部署到免费平台

### 方案 A：Hugging Face Spaces（免费，支持 Docker）

1. 注册 [huggingface.co](https://huggingface.co)；
2. New Space → Space name `moneymate` → SDK 选 **Docker**；
3. 上传项目文件（backend、frontend、Dockerfile、requirements.txt 等）；
4. 在 Space 的 Settings → Variables 里配置环境变量（如需要）；
5. 等待构建，访问 `https://huggingface.co/spaces/用户名/moneymate`。

### 方案 B：Zeabur（国内访问好）

1. 注册 [zeabur.com](https://zeabur.com)；
2. 从 GitHub 导入仓库，选 Docker 服务类型；
3. 部署后绑定域名。

### 方案 C：学生云服务器（长期稳定，约 100 元/年）

```bash
git clone https://github.com/hpx123300/money-mate
cd money-mate
docker build -t moneymate .
docker run -d -p 8000:8000 moneymate
```

记得在云控制台安全组放行 8000 端口，并配置域名 + HTTPS。

## 常见问题

| 现象 | 处理 |
|---|---|
| 端口被占用 | `docker rm -f <容器>` 后重跑 |
| 页面打不开 | 确认 `backend/app/static` 存在（跑 `./scripts/build-frontend.sh`） |
| 部署后数据丢失 | SQLite 是文件数据库，部署平台要挂持久化卷；多人使用建议换 MySQL |
