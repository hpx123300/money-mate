# 🚢 部署指南

目标：项目跑在公网 URL 上，手机能访问，简历链接能点。

## 第 0 步：安装 Docker（Mac）

1. 下载 [Docker Desktop for Mac](https://www.docker.com/products/docker-desktop/)；
2. 安装并打开，等右上角鲸鱼图标变绿；
3. 终端验证：`docker --version`。

## 第 1 步：本地 Docker 构建验证

```bash
cd money-mate
docker build -t moneymate .
docker run -p 8000:8000 moneymate
```

打开 http://127.0.0.1:8000，功能正常后再部署到云平台。

## 第 2 步：部署到免费平台

### 方案 A：Render（免费，支持 Docker，当前正在用）

1. 注册 [render.com](https://render.com)，用 GitHub 账号登录（顺便授权仓库）；
2. 点 **New +** → **Blueprint**，选择 `money-mate` 仓库并 Apply（仓库根目录的 `render.yaml` 已配好 Docker、免费套餐、健康检查）；
3. 构建完成后服务会给一个 `xxx.onrender.com` 地址；
4. 在服务页 **Environment** 添加环境变量，点 **Save & Deploy**：
   - `SEED_DEMO_DATA=true`：启动自动生成演示账号和样例账单；
   - `LLM_API_KEY=你的 DeepSeek key`：开启 AI 记账/智能分类/月度分析（不配也能用，只是 AI 功能会提示暂不可用）。
5. 重启/重新部署后 SQLite 数据会清空，属正常现象（演示站每次启动会自动生成 demo 账号）。

免费套餐注意：15 分钟没人访问会自动休眠，下次打开要等几秒唤醒；数据不持久，只适合演示。

### 方案 B：学生云服务器（长期稳定，约 100 元/年）

```bash
git clone https://github.com/hpx123300/money-mate
cd money-mate
docker build -t moneymate .
docker run -d -p 8000:8000 moneymate
```

记得在云控制台安全组放行 8000 端口，并配置域名 + HTTPS。

> 备注：Hugging Face 的 Docker Space 现在需要 PRO 订阅（2026 年起收费），Zeabur 免费版共享集群也已停止新建服务，所以这两个不再推荐。

## 常见问题

| 现象 | 处理 |
|---|---|
| 端口被占用 | `docker rm -f <容器>` 后重跑 |
| 页面打不开 | 确认 `backend/app/static` 存在（跑 `./scripts/build-frontend.sh`） |
| 部署后数据丢失 | SQLite 是文件数据库，部署平台要挂持久化卷；多人使用建议换 MySQL |
